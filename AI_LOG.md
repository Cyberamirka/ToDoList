---

## Что хорошо получалось в работе с AI

- **Сразу по делу:** из короткого ТЗ и уточнений собрался полный рабочий каркас (frontend + FastAPI + SQLite + Docker), без лишней «архитектуры ради архитектуры».
- **Учитывал правки по ревью:** CRUD уехал из endpoint’ов к модели, slim → Alpine, UI правился итеративно под Firefox/Chromium.
- **Искал причину, а не маскировал симптом:** по кнопкам и drag-handle разобрали вёрстку (ряд + `align-items`, SVG вместо обрезаемого символа), а не крутили только `margin`.
- **Проверял результат:** smoke-тесты API, пересборка Docker, очистка образов/контейнеров по запросу.
- **Документировал процесс:** `README.md` + этот лог, чтобы сдавать задание прозрачно.
